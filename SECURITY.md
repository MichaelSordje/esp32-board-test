# Security Policy

## Reporting a security issue

Do not publish passwords, WiFi credentials, private keys, tokens, or other
secrets in a GitHub issue.

For a security-sensitive problem, use GitHub's **Report a vulnerability**
(private vulnerability reporting) when that option is available for this
repository.

If private vulnerability reporting is not available, open a minimal issue
asking for a private contact channel without including exploit details or
sensitive data.

## Diagnostic data

Board-test reports and logs may contain device/network identifiers such as MAC
addresses, local IP addresses, BSSIDs, SSIDs, and serial/network diagnostics.
Review and redact files before sharing them publicly.
